# 接口清单

- Base URL：`/api`
- 认证：除登录外，均需 `Authorization: Bearer <JWT>`
- 统一响应：`{ "code": 200, "message": "success", "data": ... }`
- 分页参数：`page`（从 1 开始）、`size`；返回 `{ records, total, page, size, summary? }`
- 角色：`ADMIN` 图书管理员、`READER` 读者（这里的 `ADMIN` 是系统内角色，与 GitHub 仓库管理员无关）
- 日期：`yyyy-MM-dd`；时间：ISO-8601（如 `2026-10-28T19:30:00`）
- 业务错误统一使用响应体中的 `code` 表达：`400` 参数/业务校验、`401` 未登录/密码错误、`403` 无权限、`404` 不存在、`409` 唯一冲突、`423` 账号锁定、`500` 服务异常。

## 1. 认证与账号

| 方法 | 路径 | 权限 | 入参 | 出参 | 说明 |
| --- | --- | --- | --- | --- | --- |
| POST | `/auth/login` | 公开 | `{username,password}` | `{token,user}` | 连续失败 3 次锁定 15 分钟；记录 IP/时间 |
| GET | `/auth/me` | 登录 | — | `UserVO` | 恢复登录态；读者含 `reader` 视图 |
| POST | `/auth/logout` | 登录 | — | `null` | JWT 无状态，前端清除 Token |
| PUT | `/auth/password` | 登录 | `{oldPassword,newPassword}` | `null` | 新密码 6–32 位且不能与原密码相同 |

## 2. 图书

| 方法 | 路径 | 权限 | 入参 | 出参 |
| --- | --- | --- | --- | --- |
| GET | `/books` | 登录 | `page,size,keyword,categoryId,availability,sort` | 分页 `BookVO` |
| GET | `/books/{id}` | 登录 | — | `BookVO` |
| POST | `/books` | ADMIN | `BookRequest` | `BookVO` |
| PUT | `/books/{id}` | ADMIN | `BookRequest` | `BookVO` |
| DELETE | `/books/{id}` | ADMIN | — | `null` |

- `keyword` 模糊匹配书名、作者、ISBN、出版社、分类名。
- `availability`：`AVAILABLE` 有库存 / `UNAVAILABLE` 无库存。
- `sort`：`recommended`（默认）、`newest`、`rating`、`popular`、`title`。
- 删除限制：存在未归还副本时返回 400。
- `BookRequest`：`isbn,title,author,publisher,categoryId,totalCopies,publishYear,price,location,description`。`isbn` 唯一，馆藏总量不能低于在借副本数。

## 4. 读者

| 方法 | 路径 | 权限 | 入参 | 出参 |
| --- | --- | --- | --- | --- |
| GET | `/readers` | ADMIN | `page,size,keyword,type,cardStatus,hasOverdue` | 分页 `ReaderVO` + `summary` |
| GET | `/readers/me` | READER | — | `ReaderVO` |
| GET | `/readers/{id}` | ADMIN 或本人 | — | `ReaderDetailVO`（含 `activeBorrows/recentHistory/penalties`） |
| POST | `/readers` | ADMIN | `ReaderRequest` | `ReaderVO`，初始密码 `reader123` |
| PUT | `/readers/{id}` | ADMIN | `ReaderRequest` | `ReaderVO` |
| DELETE | `/readers/{id}` | ADMIN | — | `null`（有未还图书时禁止） |
| PUT | `/readers/{id}/card` | ADMIN | `{cardStatus}` | `ReaderVO` |

`ReaderRequest`：`studentNo,name,gender,type,cardStatus,department,major,email,phone`。
`type`：`UNDERGRADUATE` / `GRADUATE` / `TEACHER`；`cardStatus`：`ACTIVE` / `LOST` / `CANCELLED`。
学号唯一且作为读者登录账号；读者类型决定借阅上限与借期。

## 5. 借阅

| 方法 | 路径 | 权限 | 入参 | 出参 |
| --- | --- | --- | --- | --- |
| GET | `/borrow-records` | ADMIN | `page,size,readerId,bookId,status,keyword,startDate,endDate` | 分页 `BorrowRecordVO` |
| GET | `/borrow-records/my` | READER | `page,size,status,keyword,startDate,endDate` | 分页 + `summary` |
| GET | `/borrow-records/{id}` | ADMIN 或本人 | — | `BorrowRecordDetailVO`（含 `penalty`） |
| POST | `/borrow-records` | 登录 | `{readerId?,bookId}` | `{record,reader}` |
| POST | `/borrow-records/{id}/return` | ADMIN 或本人 | — | `{record,penalty,book}` |
| POST | `/borrow-records/{id}/renew` | ADMIN 或本人 | — | `BorrowRecordVO` |

- 读者自助借书时忽略/校验 `readerId` 必须为自己；管理员必须传 `readerId`。
- `status`：`BORROWED` / `RETURNED` / `OVERDUE`；`ACTIVE` 表示在借（含逾期）；`ALL` 等同不传。
- 借书校验：借阅证 `ACTIVE`、库存 > 0、未达上限、未重复借同一本。
- 还书：自动计算逾期天数（应还日之后的天数）× 每日费率；幂等，不会重复生成罚款。
- 续借：最多 1 次、逾期不可续、`reservation_count > 0` 不可续。

`BorrowRecordVO` 关键字段：

```json
  "id": 101,

  "readerNo": "2023001",

  "bookId": 30,
  "bookTitle": "三体",
  "bookIsbn": "9787536692930",
  "bookAuthor": "刘慈欣",
  "categoryName": "文学",
  "categoryColor": "#8f5c42",
  "borrowDate": "2026-10-04",
  "dueDate": "2026-11-03",
  "returnDate": null,
  "status": "BORROWED",
  "renewCount": 0,
  "overdueDays": 0,
  "canRenew": true
}
```

## 6. 预约与到书留书

| 方法 | 路径 | 权限 | 入参 | 出参 |
| --- | --- | --- | --- | --- |
| GET | `/reservations/summary` | 登录 | — | `ReservationSummaryVO` |
| GET | `/reservations/my` | READER | `page,size,status,keyword` | 分页 `ReservationVO` |
| GET | `/reservations` | ADMIN | `page,size,status,keyword` | 分页 `ReservationVO`（全馆队列） |
| POST | `/reservations` | READER | `{bookId}` | `ReservationVO`，`message` 含排队位次 |
| POST | `/reservations/{id}/cancel` | ADMIN 或本人 | — | `ReservationVO` |

- `status`：`PENDING` 排队中 / `READY` 已到书待领取 / `FULFILLED` 已借出 / `CANCELLED` 已取消 / `EXPIRED` 已过期；`ACTIVE` 表示 `PENDING + READY`。
- 预约条件：借阅证 `ACTIVE`、该书 `availableCopies = 0`、未在借同一本书、同一本书没有进行中的预约、本人有效预约不超过 5 个。
- 排队：按 `requestedAt` 先到先得，`queuePosition` 为当前位次，`aheadCount` 为前面还有几人。
- 到书留书：还书后若仍有可借副本，队首 `PENDING` 自动转 `READY`，并从可借数中扣去一册作为留书，默认保留 48 小时（`app.reservation.ready-hold-hours`，环境变量 `RESERVATION_HOLD_HOURS`）；超时未取转 `EXPIRED` 并顺延下一位。
- 领取：`READY` 状态下借书不再扣库存（副本已为其预留），预约转 `FULFILLED` 并回写 `borrowRecordId`。
- 取消：`READY` 取消会释放留书并顺延下一位；已结束的预约不可取消，越权取消返回 403。
- `summary`：`{pendingCount,readyCount,fulfilledCount,cancelledCount,expiredCount,activeCount,totalCount}`。

`ReservationVO` 关键字段：

```json

  "id": 1,

  "readerNo": "2023001",
  "readerType": "UNDERGRADUATE",
  "bookId": 33,
  "bookTitle": "雪国",
  "bookIsbn": "9787544274665",
  "bookAuthor": "川端康成",
  "categoryName": "文学",
  "status": "READY",
  "statusLabel": "已到书",
  "queuePosition": 1,
  "aheadCount": 0,
  "availableCopies": 0,
  "reservationCount": 2,
  "requestedAt": "2026-10-26T09:12:00",
  "readyAt": "2026-10-28T10:00:00",
  "expireAt": "2026-10-30T10:00:00",
  "remainingHours": 24,
  "borrowRecordId": null,
  "cancelReason": null
}
```

## 7. 罚款

| 方法 | 路径 | 权限 | 入参 | 出参 |
| --- | --- | --- | --- | --- |
| GET | `/penalties` | ADMIN | `page,size,status,keyword` | 分页 `PenaltyVO` + `summary` |
| GET | `/penalties/my` | READER | `page,size,status,keyword` | 分页 `PenaltyVO` + `summary` |
| GET | `/penalties/summary` | 登录 | — | `PenaltySummaryVO` |
| POST | `/penalties/{id}/pay` | ADMIN 或本人 | — | `PenaltyVO` |

`summary`：`{pendingCount,pendingAmount,paidThisMonth,paidThisMonthCount,collectedTotal,rate}`。
重复缴纳返回 400；管理员记为 `CASH`，读者自助记为 `ONLINE`。
`PenaltyVO` 含 `recordId,overdueDays,amount,status,paidAt,ruleRate,readerName,readerNo,bookTitle,bookIsbn,borrowDate,dueDate,returnDate`。

## 8. 统计与仪表盘

| 方法 | 路径 | 权限 | 入参 | 出参 |
| --- | --- | --- | --- | --- |
| GET | `/stats/overview` | ADMIN | `startDate,endDate?` | 管理员概览 |
| GET | `/stats/trends` | ADMIN | — | `{monthly:{labels,borrows,returns},categories:[{name,value,color}]}` |
| GET | `/stats/ranking` | ADMIN | `limit,startDate,endDate?` | `{books:[BookRankVO],readers:[ReaderRankVO]}` |
| GET | `/stats/overdue` | ADMIN | — | `{summary,trend,buckets,records,recentPenalties}` |
| GET | `/dashboard` | 登录 | — | 角色化仪表盘 |
| GET | `/notifications` | 登录 | — | `{items:[{id,tone,title,description,path}],unreadCount}` |

- `/stats/overview` 关键字段：`totalTitles,totalCopies,availableCopies,readerCount,activeLoans,overdueLoans,todayBorrows,monthBorrows,monthBorrowDelta,activeMonthReaders,pendingFineCount,pendingFineAmount,lowStockCount,rangeBorrowCount`。
- 读者登录时 `/dashboard` 返回个人概览、当前在借、最近阅读、推荐、未缴罚款、公告；管理员返回全局概览、趋势、热门榜、在借、待办、最近活动。
- 统计报表支持前端 CSV 导出；数据不落额外表，全部从业务表实时聚合。

## 10. 前端 Mock 对应

`frontend/src/mock/handlers` 按模块实现相同路径和返回结构，可用 `VITE_USE_MOCK=true`
在无后端环境下走通所有页面。将 `frontend/.env.local` 中该值改为 `false`，即可无缝切换到真实后端。
