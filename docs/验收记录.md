## 4. 真实 MySQL API 验收

方法：导入 `database/schema.sql` 与 `database/data.sql` 后启动可执行 jar，
使用 Node `fetch` 执行 48 项 API 检查。

结果：**48/48 通过**，覆盖：

- admin/reader 登录、JWT 格式、未认证 401；
- `/auth/me` 读者类型与额度；
- 图书分页/分类冗余/搜索、分类统计、读者 summary；
- 我的借阅、我的罚款、管理员四类统计接口、读者访问统计 403；
- 双角色 dashboard、通知路径；
- 分类新增/删除、图书新增、借书/库存 -1/重复借阅 400/续借/二次续借 400/归还/库存恢复/重复还书 400/删除；
- 逾期归还生成正确金额（4 天 × 0.50 = 2.00）；
- 读者缴纳罚款、重复缴纳 400、跨读者访问 403；
- 新读者创建、连续 3 次错误登录 423、删除读者。

> 种子密码也单独使用 Spring Security `BCrypt.checkpw` 验证：`admin123` 与 `reader123` 均返回 true。

## 5. 全栈浏览器联调

方法：前后端同时运行，前端 `.env.local` 设置 `VITE_USE_MOCK=false`，Vite 将 `/api` 代理到
Spring Boot，MySQL 导入种子数据。

结果：**21/21 通过**：

- 管理员真实登录、dashboard 数据全部来自 `/api`（localStorage 中没有 Mock 数据库）；
- 图书列表、关键词搜索、详情抽屉、分类、读者、罚款、统计图表；
- 流通台读取读者、确认借书、结果弹窗、还书；
- 读者真实登录、dashboard、在借、我的借阅页签 summary、馆藏、罚款、个人中心；
- 浏览器控制台无错误。
